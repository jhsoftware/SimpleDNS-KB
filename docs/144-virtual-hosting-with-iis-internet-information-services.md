# Virtual hosting with IIS (Internet Information Services)

"Virtual hosting" means hosting multiple websites with different domain names on the same IP address.

From the "Internet Information Services (IIS) Manager" window, right-click on a website, and select "Edit Bindings...":

![](img/144/1.png)

In the "Site Bindings" dialog, select the first item and click the "Edit" button:

![](img/144/2.png)

Enter the website domain name in the "Host name" field:

![](img/144/3.png)

Click the OK button in all the dialogs to save your changes.

Create additional websites the same way.
