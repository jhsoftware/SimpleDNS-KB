# How do I register an Internet Domain Name?

To register a domain name, we recommend using one of the ICANN accredited registrars. See the list at:  
[https://www.icann.org/en/contracted-parties/accredited-registrars/list-of-accredited-registrars](https://www.icann.org/en/contracted-parties/accredited-registrars/list-of-accredited-registrars){target=_blank}

You typically need to pay a yearly fee for each domain name that you register.
